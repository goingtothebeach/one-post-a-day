## 🐛 Bug修复记录

### Bug #1: 点赞/收藏计数不更新

**症状**：
- 点击点赞/收藏按钮后，图标状态会切换
- 但是计数始终显示"0"，不增加也不减少
- 后端API返回200，但前端UI不更新

**根本原因**：
1. 后端`/feed`接口只返回原始Post对象，缺少统计字段
2. 前端无法获取`likes_count`和`favorites_count`数据

**修复方案**：
```python
# server/app/post.py
@router.get("/feed")
def feed(db: Session = Depends(get_db), user=Depends(get_current_user_optional)):
    posts = db.query(models.Post).order_by(models.Post.publish_date.desc()).all()
    
    result = []
    for post in posts:
        # 统计点赞数和收藏数
        likes_count = db.query(models.PostLike).filter(
            models.PostLike.post_id == post.id
        ).count()
        favorites_count = db.query(models.PostFavorite).filter(
            models.PostFavorite.post_id == post.id
        ).count()
        
        # 检查当前用户是否点赞/收藏（如果已登录）
        is_liked = False
        is_favorited = False
        if user:
            is_liked = db.query(models.PostLike).filter(
                models.PostLike.post_id == post.id,
                models.PostLike.user_id == user.id
            ).first() is not None
            # ...
        
        # 返回完整数据
        post_data = {
            **post.__dict__,
            "likes_count": likes_count,
            "favorites_count": favorites_count,
            "is_liked": is_liked,
            "is_favorited": is_favorited,
            # ...
        }
        result.append(post_data)
    
    return {"posts": result}
```

**验证测试**：
- ✅ 第一条帖子点赞：0→1→0（取消）正常
- ✅ 第一条帖子收藏：0→1→0（取消）正常
- ✅ 第二条帖子点赞：独立计数，正常
- ✅ 刷新后状态保持

**状态**：✅ 已修复并验证通过
